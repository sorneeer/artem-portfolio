# Artiom Djur - Portfolio

Personal portfolio and CV website for Artiom Djur, a business designer and full-stack developer based in Chisinau, Moldova.

## Highlights

- Responsive single-page portfolio
- Dedicated FLQ and MOVLY case-study pages
- Experience, education, languages and technical stack
- Downloadable PDF CV
- Motion design, project transitions and reduced-motion support

## Stack

- HTML5
- Tailwind CSS via CDN
- Custom CSS animations
- Vanilla JavaScript

## Run locally

```bash
python3 -m http.server 8765
```

Open `http://localhost:8765` in a browser.

## Structure

- `index.html` - portfolio homepage
- `flq.html` - FLQ case study
- `movly.html` - MOVLY case study
- `motion.css` - shared layout and motion system
- `motion.js` - transitions and interactive effects
- `assets/` - images and downloadable CV
